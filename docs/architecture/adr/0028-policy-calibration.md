# ADR-0028：策略标定

- 状态：Accepted
- 日期：2026-10-24
- 决策者：Human（2026-10-24 在对话中确认：显式网格、目标函数为总损益、按训练区间选最优且验证只报告、验证区间必须在训练区间之后）
- 范围：AC43
- 关联：ADR-0014（PolicyArtifact）、ADR-0024 至 ADR-0027（回放）

## 背景

AC43：标定输出的 PolicyArtifact 引用训练区间、验证区间、目标函数、全部候选参数及其各自结果；训练区间与验证区间重叠时，标定请求被拒绝。

ADR-0014 规定 PolicyArtifact 装载已标定的策略，含标定窗口与标定证据。回放（ADR-0024 至 ADR-0027）已能对一个 PolicyArtifact 在一段时间上给出确定的结果与损益。

## 决策

### 1. 请求

- 一个基础 PolicyArtifact（策略族、券域、频率、结算方式、执行规则、约束声明、固定参数），以及回放所需的全部输入（数据、Subject、状态快照、约束集、资金、票息、成本、种子、代码、运行环境）。
- 参数网格：参数名 → 候选值列表。候选组合是各参数候选值的笛卡尔积，参数按名称排序、候选值按给定顺序展开。每组候选 = 基础参数被该组覆盖后的完整参数。
- 训练区间与验证区间（左闭右开）。
- 目标函数：内置族 `ficant.objective.total-pnl`（区间内总损益）。
- 输出 PolicyArtifact 的 ID 与有效期。

### 2. 校验（失败关闭）

- 两个区间都不能为空；**验证区间必须在训练区间之后**：`训练.结束 ≤ 验证.开始`。重叠或顺序相反都拒绝（AC43）。
- 网格不能为空；每个参数至少一个候选值，同一参数内候选值不能重复；组合数不超过平台上限 1024。
- 任一候选在任一区间上的回放失败，整个标定失败，不产出 PolicyArtifact。

### 3. 计算

- 每组候选分别在训练区间与验证区间上回放一次。每次回放都从空仓开始，策略有效期设为该区间，所以只有该区间内开始的 bar 参与决策与成交。
- 区间总损益 = 回放结束时的权益（起点为零），未平仓位按最后标记与应计计入。
- **按训练目标选最优**；并列时取候选顺序中靠前的一组。验证结果全部记录，但不影响选择。

### 4. 输出

- 输出的 PolicyArtifact 带 `calibration` 记录：基础策略的内容哈希、训练区间、验证区间、目标函数、参数网格、全部候选（完整参数、训练与验证各自的回放结果 ID 与目标值）、被选中候选的序号。
- PolicyArtifact 的参数必须与被选中候选的参数完全一致，否则构造失败；`calibration` 记录进入其内容哈希。
- 同样的请求得到逐位相同的 PolicyArtifact。

## 代价

- 网格穷举，组合多时回放次数随之增长；上限 1024 组。
- 只有总损益一个目标函数；风险调整目标以后按名称追加。

## 替代方案

- **随机搜索、优化器**：不穷举，结果依赖种子或算法细节，复核成本更高。暂不。
- **按验证结果选参**：等于把验证区间也用来训练，失去验证的意义。拒绝。
