# ADR-0015：全局因子体系与 FactorId 唯一性

- 状态：Accepted
- 日期：2026-07-26
- 决策者：Human
- 关联迭代：`docs/iterations/2026-08-r1-layer-contract-skeleton.md`

## 背景

跨资产风险管理有一个前置条件，业务侧研究表述得很直接：

> 「10 年期国债收益率」同时作用于 10 年国债现券、T 合约、10Y IRS、政金债、信用债、债券 ETF、可转债债底。如果这七处各自定义，组合层面的风险就加不起来——你会得到七个数字，但没有一个是全组合的真实敞口。**这一条不成立，跨资产风险管理就是假的。**

ficant 当前全 crate 无 `Factor` / `FactorId` / `Exposure` 的一等表达；`FactorDefinition` 只出现在 README 的对象清单里，代码中不存在。

这是"多资产覆盖能否成立"的唯一判据，而它现在是空的。它同时也是最不可逆的一项——一旦三个 Domain Pack 各自定义了"10 年国债收益率"，收不回来。

## 决策

### 一、FactorId 全局唯一

同一经济量在全平台**只有一个** `FactorId`。资产到因子的映射必须**双向可查**：对任意资产可答"暴露在哪些因子上、权重多少"，对任意因子可答"哪些资产受影响、总敞口多少"。双向可查是压力测试的前提。

### 二、命名规范（Human 已裁决）

```
<市场>.<类别>.<经济量>.<期限>
```

全小写，点分。示例：`cn.gov.yield.10y`。

**Worker 不得自创其他形态。** 该标识会进入所有历史血缘，落定后不可更改。

### 三、因子的分解关系必须显式

因子层级必须在模型中显式表达，不得算完再拆。例如：

```
信用债收益率 = 国债曲线关键点 + 品种利差 + 评级利差 + 行业/区域利差
             + 主体特有利差 + 流动性溢价 + 税收调整
```

理由有二：**对冲需要它**——国债期货只能对冲第一项；**归因需要它**——不显式分解就无法把收益拆回各成分。

### 四、敏感度口径统一

`SensitivityConvention` 是因子定义的一部分，至少包含：bump 幅度、单边或双边、重定价时是否重建曲线、非线性资产是否使用二阶项。

**口径不一致的敏感度不能相加，而组合风险的本质就是相加。**

### 五、中国市场特有因子必须纳入

海外风险因子体系没有"制度性"这一整块，直接搬用会漏掉中国债市最大几次波动的成因。以下因子与利率、信用、流动性因子同级：

- **税收利差**（免税老券 vs 应税新券）——2025-08-08 之后新增，中国独有，**无历史序列**
- **R-DR 利差**——非银身份的专属风险因子
- **可交割券溢价**——进入交割篮子带来的系统性偏贵
- **隐含评级迁移**——方法论产生的人造因子，但对 P&L 的影响真实
- **供给冲击**（发行日历，可提前知晓的确定性冲击）
- **机构行为**（理财赎回、债基申赎）——海外无对应物，2022 年 11 月证明是一等风险源

## 备选方案

1. **各 Domain Pack 自行定义因子，聚合时做映射。** 否决：映射本身会成为需要维护的第二真相，且映射错误不报错。
2. **用数字或 UUID 作 FactorId。** 否决：血缘对人不可读是血缘失效的主要形式。人能看懂是硬要求。
3. **先不建因子体系，等第二类资产进来再说。** 否决：这正是最不可逆的一项。一期虽只有国债与期货，但 T 合约与现券已经需要共享同一个 10Y 因子；晚建等于让第一批历史血缘带着错误标识。
4. **敏感度口径由调用方指定。** 否决：口径随调用漂移，聚合结果不可信，且不可事后修正。

## 后果

- FactorId 命名规范是本轮**最不可逆**的决定，其验证梯度应高于其余全部内容，建议由 Human 直接审阅而非依赖验收清单。
- 一期只需注册国债与期货相关的少量因子，但注册机制与双向索引必须一次建对。
- 税收利差因子在 2025-08-08 之前无历史序列，任何跨该日期的均值回复参数估计必须分段——这与结构性断点的处理规则一致。
- 因子体系建成后，"国开-国债利差"这类历史序列的可用性需重新评估：该利差过去的锚很大一部分是税收，增值税新政把锚重新洗过一遍。

## 验证与失效条件

- 验证：ACCEPTANCE `AC05`（同一经济量在三处引用同一 FactorId，且可由因子反查全部受影响资产）。
- 失效条件：若出现两个经济量在某些市场等同、在另一些市场不等同的情形（例如不同市场对"10 年期"的定义不同），命名规范需增补消歧维度；此时必须新建 FactorId，**不得复用并加注释**。
